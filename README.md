# 岩谷 努｜ポートフォリオ

[公開ホームページ](https://tsutomu-iwaya1984.github.io/)

自動車整備・販売・大型バス運転の経験と、仕事に向き合う姿勢を紹介する個人のポートフォリオです。
資格・職歴・運転歴の詳細は、別途提出する履歴書・職務経歴書で説明しています。

## 内容

- 整備経験を活かした症状・発生条件の整理
- 安全・安心で安定した乗り心地を意識した運転
- 対話、記録・報告・相談、助言を次の走行へ反映する姿勢
- 手順遵守、安全確保、確認した事実を大切にする考え方

## 制作について

本人の経験・意向をもとに文章と構成を確認し、AIの支援を用いてHTML/CSS/JavaScriptの制作・修正を進めています。
画像はすべてAI生成のコンセプトイメージです。実在の人物・車両の写真や、本人の実務実績を撮影したものではありません。
プログラミングとAIは趣味の範囲で学習しています。

## 構成

`index.html` にスタイルとスクロール進捗表示のスクリプトをまとめています。
使用画像はトップ1枚、経験のイメージ4枚です。外部のCSS/JSファイルは必要ありません。
HTMLを静的配信するGitHub Pagesで公開しています。

## 応募書類

履歴書・職務経歴書・応募フォーム用文章は応募先へ別途提出します。
公開リポジトリには提出用PDFを置いていません。
